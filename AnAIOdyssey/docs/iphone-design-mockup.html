Navigation architecture — 11 sections, 5 tabs

Chats
Sessions → chat detail. The tool-calling agent is always on.
Research
Reports list → cited report + follow-up thread. Keeps its iPad symbol for continuity.
Search
Unified search over everything — documents, notes, mail, chats, tasks, research, memories, calendar. The user-facing face of the agent's own retrieval tool.
Tasks
Scheduled tasks + agent queue in one segmented view; task results link to their artifacts.
Library
Grid of the rest: Documents · Notes · Email · Calendar · Gallery · Memory · Compare. Long-press a tile → “Add to Tab Bar” swaps personal priorities in.
Settings
Profile avatar, top-trailing on every root (Fitness/App Store pattern) — no tab spent.

One rule the whole design hangs on: teal is the interface, violet is the AI. Any violet on screen means the model is present or acting — badges, tool chips, streaming caret, memory glyphs. Users learn where the intelligence is without reading a word.

Ships as asset-catalog colors with light/dark variants, added as an aegean case to the existing AppAccent palette system — the current seven accents remain as user choices, so iPad and Mac inherit the identity for free.

HIG compliance, by construction

  • Five tabs max, never hidden; re-tap pops to root; independent NavigationStack per tab
  • Dynamic Type end-to-end — system text styles only, tested at accessibility sizes
  • 44 pt hit targets on chips, chevrons, and every input-bar control
  • AA contrast both modes; color never the only signal — states pair color with symbol + label
  • Standard gestures: swipe-back everywhere, pull-to-refresh on syncing lists, row swipe actions
  • Reduce Motion / Transparency honored — shimmer→crossfade, materials→solid surfaces
  • Haptics with restraint: success on completion, light impact on chip expand, none while streaming
  • Dynamic Island & landscape handled by standard safe-area layout — no custom insets
